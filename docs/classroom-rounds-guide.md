# Math Buddy: five-question lesson

1. Select the class. In **Teacher**, set attendance before starting. Keep a recent **Export progress** backup.
2. Choose **Five-question round**, a topic, difficulty and answer format. Use **Full screen**, then **Start five questions**.
3. Students number five answers in their notebooks and show working. Use **Show all five** for an overview; select any card to enlarge it. Diagrams and answer choices appear in the enlarged view.
4. Open **Results & checking partners** to see who checks each notebook. Partners rotate between rounds. One present student is checked by the teacher.
5. Stop writing and exchange notebooks. Select **Ready to check**, then confirm that notebooks have been exchanged.
6. Reveal each question separately. Explain the solution and accept equivalent fractions/mixed numbers where appropriate.
7. In **Results & checking partners**, cycle each result: **? → correct → attempt → blank/excluded**. The Q1–Q5 header buttons explicitly mark all present students correct for that question; adjust exceptions. Use the three page buttons for students 1–10, 11–20 and 21–30.
8. Optionally select a leader. Once all five answers are revealed and every result is marked, select **Review XP award**, check the summary, then confirm.
9. Correct earns 10 XP; an attempt earns 3; blank/excluded earns 0. The leader receives double for all five questions: maximum 100 XP instead of 50. **Undo batch award** restores both XP and skill statistics. Starting the next batch clears the previous undo.
10. Use **Practice history** to choose a topic to revisit. These are peer-reported results, not independently verified mastery scores. Spot-check a few notebooks each round.

Attendance is locked during a batch. Three classes remain independent. Questions, results, XP and history survive reloads and JSON export/import. Progress is local to this browser/site; it does not automatically move from this preview to the public site.

The English practice bank includes original templates across all twelve supplied P5 chapters, plus bridge skills from the O-NET P6 2569 blueprint. It is not an official paper, complete exam simulator or Thai-language reading preparation. Shape classification offers Easy only rather than attaching a misleading Challenge label to the same concept.
